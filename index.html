LLM tools investigators actually use, and the evaluation that keeps them honest

Report drafting was slow for boring reasons: an old SAS platform, a case tool that was hard to check details in, and information spread across three teams. I built a drafting tool on the Claude API, took it from prototype through an investigator pilot to daily use, and cut drafting time 60%. After launch the model once wrote in a policy the bank doesn't use, so we turned auto-edits off. Analysts now review every AI edit.

  • Deployed a RAG knowledge assistant over our monitoring reports with Hugging Face embeddings and answers cited back to the source notebook.
  • Scored it against a golden question set the investigators curated, with MLflow tracing on every call and faithfulness scoring on a sample of answers.
  • Checked the faithfulness scorer itself against human labeled answers. It was wrong about 1 in 10 times, so failed answers now become regression tests that get re-run on a schedule.
  • Set up a sandbox that mirrors UAT and connects to Git through MCP, where Claude Code runs with custom skills I wrote. Adopted by my team of 8, then by IT.

Securis Analytics, a crypto wallet screening platform

I built Securis because I kept wondering how the screening work I do at the bank would hold up on chain. It is a multi-tenant platform that screens wallets for sanctions and illicit exposure across 7 EVM chains, draws the transaction graph, and runs the compliance workflow after that: alerts, cases, watchlists, labels, exports, and an audit trail.

  • Designed a multi hop risk engine that weights each edge by amount, recency, frequency, and direction. A separate policy layer turns the score into a verdict, and thin evidence comes back as unknown instead of low.
  • Built an OFAC pipeline that parses Treasury's SDN advanced XML on every run and applies new designations without a restart.
  • Backed 94 endpoints with 557 tests across 46 modules in GitHub Actions, with role based access per endpoint and tenant scoped queries.
A bug I'm glad I foundI break the platform on purpose at every iteration. One round showed that gating two hop expansion on one hop exposure let a wallet that received 20,000 ETH from an illicit actor score below one that received 100 ETH. The fix was removing the gate.
